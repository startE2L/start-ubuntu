# start-ubuntu
🚀 START-UBUNTU

Автоматизированная настройка и базовая защита Ubuntu VPS.
START-UBUNTU — Bash-скрипт для первоначальной настройки Linux-серверов. Автоматизирует обновление системы, настройку SSH, UFW, Fail2ban, nftables, сетевой переадресации и установку дополнительных инструментов.
Поддерживает два режима работы: российский и зарубежный сервер.

✨ Возможности

  🔐 SSH — смена порта, установка пароля root, поддержка "ssh.service" и "ssh.socket".
  🛡️ UFW — настройка firewall и необходимых сетевых правил.
  🚫 Fail2ban — защита SSH от перебора паролей.
  🌐 nftables — настройка DNAT и MASQUERADE.
  🔀 IP Forwarding — включение переадресации IPv4.
  ⚡ LibreSpeed CLI — инструмент для проверки скорости интернет-соединения.
  📦 3X-UI KIT — опциональная установка дополнительного программного обеспечения.
  🧹 UFW Cleanup — поиск и удаление новых разрешающих правил, добавленных KIT.
  📋 Отчёт — проверка настроек и итоговый результат выполнения.

🌍 Режимы работы

🇷🇺 Российский сервер
Предназначен для VPS, который перенаправляет входящий трафик на зарубежный сервер.
Выполняется:
- Настройка SSH и UFW.
- Открытие TCP/UDP порта второго сервера.
- Настройка маршрутизации UFW.
- Включение IPv4 Forwarding.
- Создание правил DNAT и MASQUERADE через nftables.
- Установка Fail2ban и LibreSpeed CLI.
Для настройки потребуются IPv4-адрес и порт зарубежного сервера.

🌐 Зарубежный сервер
Предназначен для основного зарубежного VPS.
Выполняется:
- Настройка SSH и UFW.
- Открытие TCP/UDP портов 80 и 443.
- Открытие дополнительных UDP-портов 56000 и 56001.
- Установка Fail2ban и LibreSpeed CLI.
Настройка межсерверного NAT и IP Forwarding пропускается.

📋 Требования

- Ubuntu Server.
- Root-доступ.
- Подключение к интернету.
- Bash.
- systemd.
- Архитектура x86_64 для LibreSpeed CLI.

📥 Установка

Запуск команды от имени root:
```bash <(curl -fsSL https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/start-ubuntu)```

⚙️ Порядок настройки

1. Выберите тип сервера — российский или зарубежный.
2. Установите новый пароль root.
3. Укажите новый SSH-порт.
4. Для российского сервера укажите IPv4 и порт зарубежного VPS.
5. Дождитесь обновления системы и настройки компонентов.
6. Выберите, устанавливать ли 3X-UI KIT.
7. При необходимости выполните очистку новых правил UFW.
8. Ознакомьтесь с итоговым отчётом.

🔌 Используемые порты

Общие:
- "22/tcp" — стандартный SSH.
- "SSH_PORT/tcp" — новый SSH-порт.
- "80/tcp" и "80/udp" — HTTP.
- "443/tcp" и "443/udp" — HTTPS.

Дополнительно для зарубежного сервера:
- "56000/udp"
- "56001/udp"

Дополнительно для российского сервера:
- Указанный порт второго сервера для TCP и UDP.

💾 Резервные копии и конфигурация

Основной конфигурационный файл:
/etc/start-ubuntu.conf
Каталог резервных копий:
/etc/start-ubuntu-backups/
Конфигурация nftables:
/etc/nftables.d/start-rus.nft

⚠️ Важная информация

- Перед запуском рекомендуется создать snapshot VPS.
- Скрипт изменяет системные настройки SSH и firewall.
- Убедитесь, что новый SSH-порт разрешён в firewall провайдера.
- Не закрывайте текущую SSH-сессию до проверки нового подключения.
- При использовании существующих правил nftables проверьте их совместимость.
- Установка 3X-UI KIT выполняется из внешнего GitHub-репозитория.
- Скрипт предназначен прежде всего для первоначальной настройки Ubuntu VPS.
